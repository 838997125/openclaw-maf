# 使用指南

## 触发方式

在 OpenClaw 对话中使用以下任一方式：

| 触发词 | 说明 |
|--------|------|
| `启动多智能体：<任务>` | 完整 MAF 流程 |
| `多智能体协作：<任务>` | 同上 |
| `/maf <任务>` | 命令式 |
| `/multi-agent <任务>` | 英文命令式 |

## 半自动流程

MAF 默认走半自动模式（v2.1+），会在执行前让你确认：

1. **Phase 1**：PM 输出需求确认单（目标/约束/成功标准）
2. **Phase 2**：Planner 输出 DAG 执行计划（任务节点 + 依赖图 + 角色分配）
3. **你确认**：回复"确认"或"开始"后才真正 spawn 子 agent
4. **Phase 5-9**：自动执行、审查、返工、交付

如果是简单任务（PM 判断不需要 Multi-Agent），会直接回答并说明原因。

## 任务复杂度判定

| 复杂度 | 判定标准 | 处理方式 |
|--------|---------|---------|
| 简单 | 单一领域、<1 小时、不需要搜索 | 直接回答 |
| 中等 | 2-3 个领域、需要搜索、1-2 个交付物 | 单 agent + reviewer |
| 复杂 | 3+ 领域、需要并行、5+ 交付物 | 完整 7 角色 MAF |

## 典型适用场景

✅ 适合：
- 市场调研与竞品分析
- 战略规划与商业计划书
- 多维度技术选型
- 代码架构审查
- 深度研究报告
- 跨领域可行性分析

❌ 不适合：
- 事实性问答（直接问就行）
- 简单代码修改
- 聊天陪伴
- 单一工具调用

## 跟 PM 互动的常用指令

| 指令 | 作用 |
|------|------|
| `确认` / `开始` | 批准 DAG 计划并开始执行 |
| `修改：<要求>` | 让 Planner 调整计划 |
| `停` | 中止所有子 agent |
| `继续` | 从暂停处恢复 |
| `打回 <模块>：<原因>` | 强制返工某模块 |
| `跳过 <模块>` | 跳过非关键模块 |

## 输出结构

每次 MAF 任务完成后，会在 `~/.openclaw/workspace-<agent>/outputs/<task-slug>/` 产出：

```
<task-slug>/
├── <任务名>.md              # 最终整合报告
├── <任务名>.json            # 机读摘要
├── pm_shared_data.json     # 黑板（SSOT）
├── modules/                # 每个模块的完整原文
│   ├── L1_1_xxx_FULL.md
│   ├── L1_2_xxx_FULL.md
│   └── ...
└── session-transcripts/    # 所有会话的可读归档
    ├── INDEX.md
    ├── 00_PM_MAIN.md
    └── L*_*.md
```

## 并行数量限制

同一时间最多 spawn **3 个**子 agent（v2.0+ 硬规则），避免触发 OpenClaw Token Plan 全局速率限制。超出时分批 spawn，每批间隔 ≥ 30 秒。

## 5 轮返工保护

- 第 1-2 轮：正常返工
- 第 3 轮：PM 必须出具《风险接受声明》，告诉你哪些问题可能无法完美解决
- 第 4-5 轮：继续返工
- 超过 5 轮：自动通过 + 在终稿附录 C 标注未解决问题

## 数字一致性 Checker（v2.2 新增）

对于数字敏感的任务（市场规模、财务测算、用户数等），MAF 会：

1. **Spawn 前**：PM 先确定 5-10 个 anchor 数字（总人口、市场规模、客单价等）
2. **写入黑板**：所有子 agent prompt 必须引用 SSOT，禁止自行计算
3. **L1 完成后**：spawn 独立 checker 验证跨模块数字一致性
4. **发现冲突**：checker 出具仲裁报告，更新 SSOT，L2 模块使用更新后数字

这避免了"模块 A 说市场 23 亿、模块 B 说 55 亿"的问题。

## 故障排查

### 子 agent 输出被截断

v2.2 强制子 agent 用 `write` 工具写文件，消息只回 300 字摘要。如果仍出现截断，PM 会自动发"续补三段式"指令（断点引用 + ≤5 项清单 + ≤1500 字硬上限）。

### 子 agent 自称"已保存"但文件不存在

PM 会执行三件套验证：
- `ls -la <path>`（存在？）
- `wc -c <path>`（字节数 ≥ 预期 50%？）
- `tail -30 <path>`（结尾完整？）

任一失败立即打回。

### 子 agent 数字虚高

v2.2 要求每个分析类子 agent 结尾自报：
- 市占率（vs 行业 CR3/CR5 基准）
- 单节点月 GMV（vs 行业顶级产能）
- 投资回收期（vs 行业标杆）

偏离基准 50% 必须自我否决。

### 用户干等

PM 在 `sessions_yield` 期间，超过 3 分钟没有新事件就主动发一行进度卡片。
