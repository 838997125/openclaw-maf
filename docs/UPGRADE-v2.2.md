# v2.1 → v2.2 升级要点

发布日期：2026-08-07
实战复盘：武汉医药 O2O 战略报告（10 个子 agent、6 小时、81KB 终稿、531KB 模块原文、5.6MB 会话归档）

## 核心变化

v2.2 修复了 v2.1 在真实生产环境中暴露的 8 个问题。所有新规则**强制执行**，PM 在每个 Phase 必检。

## 新增 10 条强制规则

### 规则 1：子 agent 必须增量写文件（消息中不贴全文）

**问题**：v2.1 虽然要求写文件，但没明确"边写边存"，导致 9/10 模块在消息里输出全文然后被截断。

**v2.2 要求**：prompt 必须含：

```
## 输出要求（强制）
1. 用 write 工具将完整报告写入绝对路径：/abs/path/to/file.md
2. 每写完一章立即 write 一次（增量写入）
3. 报告 >3000 字时严禁在消息正文中贴全文
4. 消息只回复三行：已保存路径 / 字节数 / 自检结果
```

### 规则 2：完成事件三件套验证

**问题**：子 agent 回"已保存"，但实际文件可能不存在或被截断。

**v2.2 要求**：收到 completed 事件后立即跑：

```bash
ls -la <output_path>
wc -c <output_path>
tail -30 <output_path>
```

任一不达标立即打回。

### 规则 3：预-spawn SSOT 基线

**问题**：L1 三个模块对"武汉药店总数"给出 4800 / 7500 / 4200 三个数，事后才发现冲突。

**v2.2 要求**：数字敏感型任务（市场/财务/用户数）在 spawn 前：

1. PM 用 1-2 次搜索确定 5-10 个 anchor 数字
2. 写入 `pm_shared_data.json.ssot`
3. 所有子 agent prompt 含"数字铁律"段落
4. 表外数字必须先请 PM 更新黑板

### 规则 4：子 agent 自检三项

**问题**：L1.6 财务预测 2028 年 GMV 25.8 亿，需要占武汉市场 57%，子 agent 没意识到不现实。

**v2.2 要求**：报告结尾必须自报：

- **市占率** = 目标 GMV ÷ 全市场规模（vs 行业 CR3/CR5）
- **单节点产能** = 月 GMV ÷ 节点数（vs 行业顶级产能）
- **投资回收期**（vs 行业标杆）

任一偏离行业基准 50%，必须显式说明假设或自我否决。

### 规则 5：续补三段式

**问题**：PM 发的续补指令本身太长，子 agent 续补时又被截断，还要再发一次。

**v2.2 要求**：续补指令严格三段：

```
你的报告在"<引用最后 20 字>"处截断。请直接从断点续接：
1. <必补项 1>（≤30 字）
2. <必补项 2>
... (≤5 项)

要求：直接输出 Markdown，不写引导语，总字数 ≤1500。
```

### 规则 6：3 分钟心跳

**问题**：yield 后用户干等 5-7 分钟，追问"你为啥停了"。

**v2.2 要求**：yield 期间超 3 分钟无新事件，PM 主动发：

```
⏳ 等待中：L2.3 财务重算（已 4m12s），L2.1/L2.2 已完成
```

### 规则 7：黑板强制创建（v2.1 已有，强化）

Phase 1 必须 write `pm_shared_data.json`，后续每个 agent 读它。

### 规则 8：Reviewer 问题必须精准返工（v2.1 已有，强化）

P0/P1 错误必须 spawn 原子 agent 重做，PM 不得静默修改。

### 规则 9：绝对路径硬约束

**问题**：L2.2 把文件写到了 `output/` 而不是 `outputs/wuhan-o2o/modules/`。

**v2.2 要求**：
- output_path 必须以 `/` 开头
- prompt 中任务头和输出要求段落重复 2 次完整绝对路径
- 禁止用"./"、"当前目录"等相对表述

### 规则 10：完成即归档 FULL 版

**问题**：v2.1 没有即时归档，事后派归档 agent 回溯 session 历史，浪费 token 和时间。

**v2.2 要求**：每个模块通过 PM 审核后立即：

```bash
cp <output_path> <modules_dir>/<TASK_ID>_FULL.md
```

终稿组装阶段用 Python 脚本拼接（>5 个模块时不要手工粘）。

## 兼容性

v2.2 完全向后兼容 v2.1：
- 触发词不变
- 七角色不变
- 18 步流程不变
- 黑板 schema 不变

只在"强制执行清单"里新增/强化了规则。
