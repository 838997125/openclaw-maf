## 一、武汉地理与配送环境

- 总面积8569.19km²、13区、1380.91万常住人口、城镇化85%
- 长江+汉江天然分割，形成"三镇"：武昌片（武昌/青山/洪山）、汉口片（江岸/江汉/硚口）、汉阳片（汉阳+经开+蔡甸东）
- 汉江桥梁密度高，汉口↔汉阳可视为一个协同圈
- 三环线是30分钟达物理边界，三环-四环60分钟+前置仓，四环外中心镇卫星店

## 二、30分钟达覆盖模型

- 3公里直线半径 = 实际骑行4.5km
- 电动车15-20km/h → 11-16分钟骑行 + 拣货3-5分钟 + 等灯电梯5-8分钟 = 25-30分钟
- 半径从1→3公里，覆盖人群从6.25万→25万+（4倍效应）

## 四、前置仓布局

### 单仓经济模型
- 投资：装修8万+设备15万+库存45万+证照5万+押金12万+流动15万 = 100万
- 保守：日80单×45元 = 月10.8万营收、月成本8.5万、月利2.3万、回本18-24月
- 目标：日200单×65元 = 月39万营收、月成本16万、月利7.5万、回本10-14月

### 三种仓模式对比
- 美团闪电仓：投资60-90万、佣金15-20%、数据归平台、快速铺开
- 自建前置仓：投资70-110万、技术服务费5-8%、数据自有、深耕核心
- 京东秒送合作：投资30-50万、佣金10-15%、京东品质心智、流量较小

## 五、配送模式选择

- 平台骑手单均4-7元，0管理但品质不可控
- 自营骑手武汉月薪5000-7000元，单均5.5-7.7元，品质可控
- **推荐混合模式**：高峰平台兜底、平峰自营保品质、夜间众包+24h P仓
- 远城区：乡镇合伙人+众包
- 自营骑手承担40-50%订单，综合单均成本6-8元

## 六、冷链与特殊药品配送

- 2-8℃全程温控、医用保温箱（10-20L、保温层≥5cm）、冰排预冷12h、2cm珍珠棉隔离
- 温度记录仪放箱内几何中心，≤10分钟/次
- 交接≤5分钟，超标即弃
- 不得放快递柜/门卫/楼道

## 七、库存与SKU

### 分级补货
- S级：30天安全库存、每日补货、4h紧急调拨
- A级：21天、3次/周、次日达
- B级：15天、2次/周
- C级：10天、1次/周
- P级：7天、每日直配、仓间2h紧急调拨

### 区域仓-店调拨
- 武昌/汉口/汉阳各设1个区域中转仓（共500万CapEx）
- 常温厢式车每日2班，冷链冷藏车每日1班

## 九、核心结论

1. 分镇组网、不跨江配送
2. P级前置仓是核心增长极（中位投资85-100万、回本14-18月）
3. 混合运力是最优解
4. 冷链合规即护城河
5. 3年7,500-8,500万净投入换全域覆盖
