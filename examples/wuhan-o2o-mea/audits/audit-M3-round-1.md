## 4. 违规词扫描

```
$ grep -nE "根治|最佳|100%|药到病除|完全无风险|绝对|彻底治愈" modules/M3-regulation.md
585:- 全文已避免使用"根治/最佳/100%/完全无风险/药到病除"等违规或绝对化用语；O2O 业务提示采用合规、审慎表述。
```

**结论**：正文中无广告法语境下使用违规词；唯一段命中出现在附录"自检结论"中，属于声明性引用，被合规扫描器（如广告法关键词扫描）误报的可能性存在但风险低。建议改写为不直接列出禁用词字符串的表述（如"全文未出现广告法明令禁止的绝对化/功效保证类用语"），避免被客户侧自动化扫描误判。

其他绝对化用语扫描（"第一""最""首选""唯一""国家级"等）：正文 §1.3"三句话结论"、§10 建议段使用了"主战场""高压线""不可妥协"等业务化修辞，不属于广告法绝对化用语，可接受。
